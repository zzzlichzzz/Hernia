Формат пакета на проводе
text

┌──────────────────── ЗАГОЛОВОК (8 байт) ─────────────────────┐
│ [ 2B type ][ 2B body_len ][ 2B frag_id ][ 2B total_frags ]  │
├──────────────────────────────────────────────────────────────┤
│ [ ... body_len байт тела ... ]                               │
└──────────────────────────────────────────────────────────────┘

type = 1-10       → служебные (PING, WELCOME, AUTH_* ...)
type = 100-65635  → генерируемые (100 + hash(name) & 0xFFFF)
API справочник
text

NetworkActionManager:
  setup(net)                          Инициализация
  on_action(name, handler)            Подписка: (peer_id, data) → void
  on_validate(name, validator)        Валидация: (peer_id, data) → bool
  send_action(name, args)             Отправка (событийная или тиковая)
  send_action_now(name, args)         Принудительная немедленная отправка
  send_action_to(peer_id, name, args) Сервер → конкретному пиру
  set_send_rate(name, hz)             Изменить герцовку в рантайме
  set_kick_callback(callback)         Callback для автокика
  clear_peer_data(peer_id)            Очистка при отключении

NetworkManager:
  create_server(port, max_clients)    Создать сервер
  create_client(address, port)        Подключиться
  send_to_server(pkt, ch, flags)      Клиент → сервер
  send_to_peer(id, pkt, ch, flags)    Сервер → конкретному
  broadcast(pkt, ch, flags)           Сервер → всем
  broadcast_except(id, pkt, ch, f)    Сервер → всем кроме
  kick_peer(id)                       Кикнуть
  shutdown()                          Закрыть всё
  is_server() → bool
  get_my_id() → int
  get_peer_ids() → Array
  signal peer_connected(id)
  signal peer_disconnected(id)

PlayerManager:
  setup_client(scene, container)      Клиент: для спавна нод
  add_player(id, pos, rot)            Добавить
  remove_player(id)                   Удалить
  update_player(id, pos, rot)         Обновить
  get_player_data(id) → Dictionary    {position, rotation, node}
  has_player(id) → bool
  get_all_ids() → Array
  clear()                             Удалить всех
