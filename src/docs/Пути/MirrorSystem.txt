							Общее описание:
Система зеркалирования состоит из двух скриптов, которые работают в связке для синхронизации файлов 
между папкой проекта (res://src/) и папкой игры (рядом с .exe или user:// в редакторе).

Проект (res://src/)  ←→  Папка игры (рядом с exe)
--------------------------------------------------------------------------------
							Компоненты системы:
1. MirrorFolder — Зеркальное копирование (Проект → Игра)
Копирует файлы из проекта в папку игры. Запускается автоматически при старте.

2. MirrorSync — Зеркальная синхронизация (Игра → Проект)
Синхронизирует измененные файлы из папки игры обратно в проект. Запускается автоматически 
после MirrorFolder.
--------------------------------------------------------------------------------
							Принцип работы:
Направление движения файлов:
1. MirrorFolder:  res://src/  →  [Папка игры]/src/
2. MirrorSync:    [Папка игры]/src/  →  res://src/
Фильтрация по расширениям:
Оба скрипта используют одинаковую логику фильтрации:

Расширения в списке excluded_extensions — НЕ копируются

Папки из списка included_folders — ТОЛЬКО их копируем (если список пуст - копируются все)
--------------------------------------------------------------------------------
							Настройка скриптов
Общие настройки для обоих скриптов:
gdscript
# Какие расширения НЕ копировать
@export var excluded_extensions: Array[String] = [
	"gd",      # скрипты
	"tscn",    # сцены
	"escn",    # сцены (instanced)
	"import",  # файлы импорта
	"godot",   # файлы проекта
]

# Какие папки обрабатывать (пусто = все)
@export var included_folders: Array[String] = [
	# "assets/textures/",
	# "assets/models/",
	# "data/",
]
--------------------------------------------------------------------------------
						Что попадает в папку игры

Тип файла     Расширения         Копируется?

Скрипты       .gd                  ❌ Нет
Сцены         .tscn, .escn         ❌ Нет
Текстуры      .png, .jpg, .jpeg    ✅ Да
Модели        .obj, .gltf, .glb    ✅ Да
Аудио         .ogg, .mp3, .wav     ✅ Да
Ресурсы       .tres, .res          ✅ Да
Данные        .json, .txt          ✅ Да (если не исключены)
--------------------------------------------------------------------------------
							⚠️ Важные моменты

Порядок в автозагрузке важен — MirrorFolder должен быть перед MirrorSync

Пути всегда через PathManager

Не копируйте скрипты и сцены — они должны оставаться в проекте

Проверяйте логи — оба скрипта показывают что скопировано/пропущено
