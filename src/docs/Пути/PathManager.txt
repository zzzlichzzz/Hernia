PathManager - это глобальный менеджер путей для Godot, который упрощает работу с двумя папками:

Папка игры - где лежит экспортированная игра (или user:// в редакторе)

Папка проекта - res:// где хранятся исходники
--------------------------------------------------------------------------------
В инспекторе Godot можно настроить, какие расширения относятся к папке игры:

PathManager.gd

@export var game_extensions: Array[String] = [
	"png", "jpg", "jpeg",  # Изображения
	"ogg", "mp3", "wav",   # Аудио
	"obj", "gltf", "glb",  # Модели
	"tres", "res",         # Ресурсы
]
Все расширения не указанные в этом списке автоматически направляются в папку проекта.
--------------------------------------------------------------------------------
Основные команды:

game(path: String)              # Путь к файлам рядом с игрой
project(path: String)           # Путь файлов проекта
smart(path: String)             # Умный путь, сам выбирает куда обращаться
--------------------------------------------------------------------------------
Примеры использования : 
PathManager.smart("src/assets/textures/atlas/block_atlas.png")  # → game (png в списке)
PathManager.smart("src/scripts/test.gd")                        # → project (gd не в списке)
PathManager.smart("src/data/settings.tres")                     # → game (tres в списке)
Можно так же указывать путь так: ("res://src/assets/textures/atlas/block_atlas.png")
