 2. ФОРМАТ ПАКЕТА
════════════════════════════════════════════════════════════════════

Заголовок: 7 байт, little-endian

┌──────────┬────────────┬───────────────┬──────────────────┬──────────┐
│ 1B type  │ 2B body_len│ 2B fragment_id│ 2B total_fragments│ body... │
└──────────┴────────────┴───────────────┴──────────────────┴──────────┘

• total_fragments == 0  →  обычный пакет (не фрагментирован)
• total_fragments >  0  →  фрагмент, fragment_id от 0 до total-1
• body_len — длина тела ЭТОГО пакета/фрагмента
• MAX_FRAGMENT_BODY = 1024 байт

 3. ТИПЫ СООБЩЕНИЙ
════════════════════════════════════════════════════════════════════

┌────┬─────────────────┬───────────┬──────────────────────────────┐
│ ID │ Имя             │ Канал     │ Описание                     │
├────┼─────────────────┼───────────┼──────────────────────────────┤
│  1 │ CONNECT         │ —         │ (зарезервировано, ENet event)│
│  2 │ DISCONNECT      │ —         │ (зарезервировано, ENet event)│
│  3 │ PING            │ reliable  │ Клиент → Сервер (heartbeat)  │
│  4 │ PONG            │ reliable  │ Сервер → Клиент (ответ)      │
│  5 │ PLAYER_UPDATE   │ unreliable│ Позиция + поворот (20 Гц)    │
│  6 │ PLAYER_JOINED   │ reliable  │ Сервер → Все: новый игрок    │
│  7 │ PLAYER_LEFT     │ reliable  │ Сервер → Все: игрок ушёл     │
│  8 │ WELCOME         │ reliable  │ Сервер → Клиент: твой id     │
└────┴─────────────────┴───────────┴──────────────────────────────┘

─── PacketTypes (static) ──────────────────────────────────────────

  # Общие
  write_packet(type, body, frag_id=0, total=0) → PackedByteArray

  read_ping(buf)                        → Dictionary {}
  read_pong(buf)                        → Dictionary {}
  read_welcome(buf)                     → Dictionary {id, position, rotation}
  read_player_joined(buf)               → Dictionary {id, position, rotation}
  read_player_left(buf)                 → Dictionary {id}
  read_player_update(buf)               → Dictionary {id, position, rotation}

 7. ПОРЯДОК СОБЫТИЙ ПРИ ОТКЛЮЧЕНИИ
════════════════════════════════════════════════════════════════════

Штатный выход:
  Клиент → disconnect_from_server()
  ENet отправляет DISCONNECT
  Сервер → peer_disconnected(id)
		 → pm.remove_player(id)
		 → broadcast PLAYER_LEFT(id)
  Остальные клиенты → pm.remove_player(id) → queue_free() нода

Таймаут (крэш клиента / kill процесса):
  ENet не получает ACK ~5 сек → EVENT_DISCONNECT
  Дальше как штатный

Heartbeat (клиент не шлёт ничего >10 сек):
  Сервер → _check_heartbeats() → kick_peer(id)
  ENet генерирует DISCONNECT → дальше как штатный

 9. КАК ДОБАВИТЬ НОВЫЙ ТИП СООБЩЕНИЯ
════════════════════════════════════════════════════════════════════

Пример: добавляем CHAT_MESSAGE (id=20)

Шаг 1: packet_types.gd
────────────────────────
  # В enum:
  CHAT_MESSAGE = 20,

  # Сериализация:
  static func write_chat(sender_id: int, text: String) -> PackedByteArray:
	  var b := StreamPeerBuffer.new()
	  b.big_endian = false
	  b.put_32(sender_id)
	  var utf := text.to_utf8_buffer()
	  b.put_32(utf.size())
	  b.put_data(utf)
	  return write_packet(CHAT_MESSAGE, b.data_array)

  static func read_chat(buf: StreamPeerBuffer) -> Dictionary:
	  var sender := buf.get_32()
	  var len    := buf.get_32()
	  var utf    := buf.get_data(len)[1]
	  return { "sender": sender, "text": utf.get_string_from_utf8() }

Шаг 2: Регистрация обработчика
───────────────────────────────
  # На сервере (server_main.gd → _ready):
  _net.register_handler(PacketTypes.CHAT_MESSAGE, _on_chat)

  func _on_chat(peer_id: int, body: StreamPeerBuffer) -> void:
	  var data := PacketTypes.read_chat(body)
	  # Пересылаем всем
	  var pkt := PacketTypes.write_chat(peer_id, data["text"])
	  _net.broadcast(pkt)

  # На клиенте (client_main.gd → _ready):
  _net.register_handler(PacketTypes.CHAT_MESSAGE, _on_chat)

  func _on_chat(_peer_id: int, body: StreamPeerBuffer) -> void:
	  var data := PacketTypes.read_chat(body)
	  print("[чат] Игрок %d: %s" % [data["sender"], data["text"]])

Шаг 3: Отправка
────────────────
  var pkt := PacketTypes.write_chat(_my_id, "Привет!")
  _net.send_to_server(pkt)

 14. ЧАСТЫЕ ОШИБКИ И РЕШЕНИЯ
════════════════════════════════════════════════════════════════════

Проблема: "Static function not found in PacketTypes"
Причина:  Забыты хелперы в packet_types.gd после обновления
Решение:  Убедиться что все write_*/read_* функции на месте

Проблема: Клиент видит свою капсулу красной
Причина:  MeshInstance3D не скрыт в player.gd
Решение:  _mesh.visible = false в _ready()

Проблема: Игрок проваливается сквозь VoxelTerrain
Причина:  Коллизии не включены в VoxelTerrain
Решение:  Инспектор → VoxelTerrain → collision_enabled = true

Проблема: Heartbeat timeout кикает при нормальной игре
Причина:  PING_INTERVAL > HEARTBEAT_TIMEOUT
Решение:  PING_INTERVAL (3с) должен быть << HEARTBEAT_TIMEOUT (10с)

Проблема: Фрагменты не собираются
Причина:  Разные type или sender_id
Решение:  Ключ сборки = (sender_id, type). Один тип за раз от одного пира.

Проблема: Порт занят при запуске сервера
Решение:  godot --headless -- --port 8081
